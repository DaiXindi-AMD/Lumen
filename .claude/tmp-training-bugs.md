### [2026-08-26 hip-rewrite-recon-philox-is-a-third-of-the-kernel]
- Ask: decide whether a hand-written HIP dual-layout quantizer can hit the ~2x the 1.6x goal needs, before spending 1-2 weeks on it.
- New tool `benchmarks/inspect_dual_layout_asm.py`: compiled resources + AMDGCN instruction mix per production shape. **Zero spills on every shape**, VGPR 84-118, occupancy 4-5 waves/SIMD, LDS 16-32KB, and the stream is 66-78% plain VALU vs 0.6-1.0% MFMA and <1% memory. No register pressure to relieve, no memory schedule to fix; a rewrite has to *remove arithmetic*, not reschedule it.
- **Where the arithmetic is** (`grad gate_up`, 2415 instructions): Philox 796 = **33%** (`v_xor_b32` 386, `v_mul_lo_u32` 210, `v_mul_hi_u32` 200); address/bit math ~468 = 19%; amax ~262 = 11%; `v_cvt_scalef32_sr_pk_fp4_f32` 64 = 3%; `v_mfma_f32_16x16x16_bf16` 16 = 0.7%. A third of the kernel generates random numbers, which Triton is not worse at than HIP.
- **`v_prng_b32` ruled out as a Philox replacement** (`benchmarks/probe_prng_b32.py`; the instruction assembles for gfx950 and the SR pk instruction already uses it internally for lane 2, so half of production's dither is already its output). It is a pure bijective *linear* map: popcount not preserved (not a bit permutation), but some output bit equals some input bit exactly, i.e. GF(2) with a pass-through field = xorshift step. Uniform on uniform input (worst bit |p-.5|=0.0011 vs 0.00195 tol, byte chi2/df=1.00); **fails outright on the counter sequence 0,1,2,...** (|p-.5|=0.5, chi2/df=4112); `prng(0)=0` fixed point. Chaining keeps each state marginally uniform but every step pair tested has a bit pair agreeing 100%. Fatal argument is entropy, not form: a bijection on 32 bits means the whole chain is a deterministic function of the seed and carries 32 bits total, so one chain cannot dither a 32-element block independently. Hardware sharing a seed across *2* adjacent elements is a bounded trade; 32 is not.
- **Positive result: `SR_PHILOX_ROUNDS` 7 -> 4 is worth 1.13-1.16x on every gradient shape** (`benchmarks/bench_sr_philox_rounds.py`). Philox share 33% -> 20%. Unbiasedness holds at every round count (resid mean stays sampling noise, as the hardware SR instruction guarantees) but resid **std** is flat at 0.0205 for rounds 7/5/4 then jumps to 0.0992 at 3 and 0.1651 at 2 -- the dither losing independence across the block. **4 is the floor.**

- Second cause: even with the transpose kernel in place, one fwd+bwd through `quantized_linear` at Qwen3-8B shapes costs **21.8 ms in FP8 delayed against 16.4 ms in BF16 and 13.5 ms in MXFP4** (sum over qkv/attn_out/gate_up/down, 16384 tokens).
