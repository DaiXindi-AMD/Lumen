Baseline

Library-level lossless/numerically-equivalent optimizations (on by default): frozen weight cache, skip WGrad, bpreshuffle GEMM, AITER attention, fused RMSNorm/RoPE, RMSNorm backward kernel, FP8 GEMM gfx942 tune, zero-copy RoPE. Memory-for-speed (off by default; OK for 8B / not for 70B): disable grad-ckpt, SHARD_GRAD_OP. Last six steps (attn/norm/rope/RMSNorm-bwd/GEMM-tune/zero-copy-rope) are model/kernel-level optimizations, applicable to both FSDP1/FSDP2.

③ Bottleneck composition changes

Before optimization, nearly half of GPU time went to copy/recompute/comm; after optimization these largely disappear — what remains is almost all unavoidable GEMM compute.

⑥ FSDP2: FP8 param-storage + model/kernel-level optimizations

First 6 steps are FSDP1. FSDP2 (fully_shard, per-parameter sharding) adds: ① FP8 param-storage (OOM prevention for large models); ② AITER attn + fused RMSNorm/RoPE + RMSNorm backward kernel + gfx942 GEMM tune + zero-copy RoPE (lossless/numerically equivalent, FSDP1/2 universal).

FP8 param-storage (FSDP_FP8_PARAM_STORAGE=1): frozen base weights stored as FP8 in shards, quantized shard-by-shard inside all-gather (Blockwise2DFP8Param.fsdp_pre_all_gather), all-gather FP8 instead of BF16 (~half param comm).

This is not the fastest 8B config — every all-gather (two forwards per step under grad-ckpt) re-quantizes → copy/elementwise explodes (1419ms/step). Its value is memory: makes 70B fit. Verified llama2-70B param-storage reaches val_loss 0.9235 @450 (token-only normalization, numerically bit-identical). For 8B speed, use cache_frozen_weight (quantize once).

⑦ How to use

FSDP2 all optimizations (fastest 8B, 568ms, sufficient memory; RMSNorm backward kernel + gfx942 GEMM tune active via AITER image, zero-copy RoPE default in Lumen):
FSDP_VERSION=2 CACHE_FROZEN_WEIGHT=1 BPRESHUFFLE=1 GRAD_CKPT=0 \
SHARDING=shard_grad_op LIMIT_ALL_GATHERS=0 FORWARD_PREFETCH=1 \
AITER_ATTN=1 LUMEN_NORM=1 FUSE_ROPE=1 MODE=fp8_blockwise2d \
  bash examples/qwen3/run_qwen3_fsdp_mi308.sh
FSDP1 (960ms, remove fusion trio and FSDP_VERSION). Large-model OOM prevention: FSDP_VERSION=2 FSDP_FP8_PARAM_STORAGE=1, remove GRAD_CKPT=0/SHARDING and cache_frozen_weight.
